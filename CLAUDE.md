# Desvenda

App de estudos com um tutor de IA (a arara) que responde a partir das anotações do próprio aluno (RAG) e com uma progressão de expedição.

- Leia `.specify/memory/constitution.md` antes de começar: SDD e TDD são obrigatórios.
- Uma issue do GitHub é uma spec, uma branch e um PR. Rode `/speckit-specify` com `--number` igual ao número da issue.
- O usuário acompanha a implementação para aprender: trabalhe em passos pequenos, explique cada um e pare nos pontos de decisão.
- Backend em `backend/` (Django, Django Ninja, pgvector, LangChain); frontend em `frontend/` (Next.js).
